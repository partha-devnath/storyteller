## Trust Boundaries

| Boundary                    | Description                                                                               |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| browser → card/proposal API | Drag-drop status patches + approve/reject actions cross here — session-authed, org-scoped |
| markdown render             | Card bodies are user/AI-authored — XSS via markdown is a real risk                        |

## STRIDE Threat Register

| Threat ID | Category               | Component                           | Disposition | Mitigation Plan                                                                                                                                                                                      |
| --------- | ---------------------- | ----------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-07-01   | Scripting (XSS)        | react-markdown card body            | mitigate    | react-markdown does NOT render raw HTML by default (no rehype-raw plugin); no dangerouslySetInnerHTML anywhere in the drawer; comment bodies render the same way                                     |
| T-07-02   | Tampering              | drag-and-drop status                | mitigate    | useMoveCard PATCHes only { status } against updateCardSchema (.strict()) server-side; closed cards are not draggable in the UI AND the API 409s closed-card updates (plan 01-05) — double protection |
| T-07-03   | Tampering              | approve/reject actions              | mitigate    | Buttons call the org-scoped API; server re-checks role (member+ required) — viewer UI hides buttons but the API enforces regardless                                                                  |
| T-07-04   | Information disclosure | deep link card slug                 | mitigate    | CardDetailPage resolves through the org-scoped project detail; unknown/other-org slugs render the drawer's not-found state, never leak card data (API returns 404/403)                               |
| T-07-05   | Tampering              | diff panel data                     | mitigate    | Diff renders version snapshots fetched from the API (immutable card_version rows); no client-side mutation of history                                                                                |
| T-07-SC   | Tampering              | npm dnd-kit / react-markdown / diff | mitigate    | Blocking-human checkpoint (Task 1) verified all three packages on npmjs before install; versions pinned exact                                                                                        |

</threat_model>
