## Trust Boundaries

| Boundary                   | Description                                                                                                            |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| API route → vector helper  | Query strings (card ids, project ids, search text) cross here — ids must be pre-scoped by the route layer (plan 01-05) |
| helper → LLMProvider.embed | Card text content is sent to the embed model — server-side only                                                        |

## STRIDE Threat Register

| Threat ID | Category        | Component                    | Disposition | Mitigation Plan                                                                                                                                                                        |
| --------- | --------------- | ---------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-03-01   | Spoofing        | embedCard/semanticSearch ids | mitigate    | Helpers treat ids as opaque tokens; org/project authorization happens in the route layer (plan 01-04/01-05 org-scope middleware) before any helper call — no cross-tenant vector reads |
| T-03-02   | Info disclosure | card text → embed provider   | mitigate    | embed() runs server-side only; the package has no client exports and nothing from @workspace/vector is imported by the web app                                                         |
| T-03-03   | Tampering       | embedding rows               | mitigate    | embedCard deletes-then-inserts within the same card id; approval-time reindex is invoked inside the proposal apply transaction (plan 01-05) so partial states cannot persist           |
| T-03-SC   | Tampering       | npm installs                 | accept      | No new npm dependencies in this plan (workspace-internal packages only)                                                                                                                |

</threat_model>
