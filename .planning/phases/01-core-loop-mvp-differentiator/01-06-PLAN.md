## Trust Boundaries

| Boundary         | Description                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| browser → API    | All requests cross the existing apiClient (credentials: "include") — session cookie is the identity |
| web bundle → env | VITE\_\* vars only; server secrets must never appear in the bundle                                  |

## STRIDE Threat Register

| Threat ID | Category               | Component                 | Disposition | Mitigation Plan                                                                                                                                                                   |
| --------- | ---------------------- | ------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-06-01   | Information disclosure | AI/API keys               | mitigate    | The web app reads ONLY VITE\_\* env vars; OPENAI_API_KEY / ANTHROPIC_API_KEY exist solely in apps/api/.env — never referenced in apps/web (grep gate in verification)             |
| T-06-02   | Tampering              | role badge / org switcher | mitigate    | Role + memberships come from the API (org-scoped), never from client storage; the UI only suppresses buttons for viewer — the API re-enforces every permission (defense in depth) |
| T-06-03   | Tampering              | forms                     | mitigate    | All forms use RHF + zodResolver with the plan 01-01 schemas mirrored client-side; server re-validates (validateBody)                                                              |
| T-06-04   | Spoofing               | nav to org pages          | mitigate    | Org ids come from useOrgs() results (server-listed memberships only); no free-form org id entry in UI                                                                             |
| T-06-05   | Scripting (XSS)        | landing page / chat text  | mitigate    | Chat renders AI responses as plain text (no dangerouslySetInnerHTML); markdown rendering (plan 01-07 drawer) uses react-markdown which does not render raw HTML by default        |
| T-06-SC   | Tampering              | npm installs              | accept      | No new npm dependencies in this plan                                                                                                                                              |

</threat_model>
