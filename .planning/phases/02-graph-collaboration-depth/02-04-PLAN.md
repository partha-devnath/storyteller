## Trust Boundaries

| Boundary                | Description                                                                                              |
| ----------------------- | -------------------------------------------------------------------------------------------------------- |
| user input→comment body | Untrusted text with embedded @tokens enters the app; must render as text + constructed chips, never HTML |
| SSE stream→drawer state | Server-pushed comment events update UI state without user action                                         |
| API→mention data        | Org member names are displayed; only org members' names arrive (server-scoped)                           |

## STRIDE Threat Register

| Threat ID | Category        | Component                                         | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                  |
| --------- | --------------- | ------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-02-31   | Tampering       | Comment body / mention rendering (XSS)            | mitigate    | parseMentionSegments produces plain-text segments + constructed spans only; no dangerouslySetInnerHTML, no rehype-raw (Phase 1 grep gates re-checked: `grep -c dangerouslySetInnerHTML apps/web` and `grep -c rehype-raw apps/web` both stay 0); React escapes all text children |

| T-02-33   | Spoofing        | SSE-driven UI updates                             | mitigate    | Events are server-authored (02-01 event bus); the client ignores unknown event types and only invalidates the two documented query keys; payloads are JSON.parse'd defensively in useProjectEvents (02-02)                                                                       |
| T-02-34   | Info Disclosure | Org member names in picker                        | mitigate    | useOrgMembers hits the org-scoped members endpoint (server enforces membership); the picker only renders what that endpoint returns                                                                                                                                              |
| T-02-35   | Tampering       | Comment payload size/abuse                        | mitigate    | Server zod schema caps body at 5000 chars (existing commentSchema); the composer trims whitespace and disables Post on empty input                                                                                                                                               |
| T-02-SC   | Tampering       | npm installs                                      | accept      | No installs in this plan                                                                                                                                                                                                                                                         |
