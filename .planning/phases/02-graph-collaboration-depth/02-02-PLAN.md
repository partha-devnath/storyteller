    Implementation: useEffect keyed on projectSlug opens `new EventSource(`${API_URL}/api/projects/${projectSlug}/events`, { withCredentials: true })`. onopen → status "open"; onerror → status "closed" (EventSource auto-reconnects; do not manually recreate); onmessage/`addEventListener("comment.created"|"card.created"|"card.updated"|"proposal.ready")` → invoke the matching handler. Event payload arrives as `event.data` JSON — parse defensively (try/catch, ignore malformed). Unknown event types are ignored. Cleanup on unmount: close(). `reconnect` = close + re-run the effect (use a nonce state in the deps). Status state: "connecting" until first open. The hook must ignore events when projectSlug is undefined (return closed + noop reconnect).
