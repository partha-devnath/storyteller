<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build-time env → web bundle | VITE_* vars are baked into the static bundle — anything placed here is public (only non-secret values like VITE_APP_ENV / VITE_API_URL) |
| deploy step → database | Migrations run as a separate step before traffic — a broken migration blocks deploy, never corrupts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-70 | Info Disclosure | VITE_* build vars | mitigate | DEPLOYMENT.md explicitly states VITE_* vars are public (env indicator + API URL only); secrets (STRIPE_SECRET_KEY, WEBHOOK_SECRET, OPENAI_API_KEY) are server-side runtime env, never VITE_* |
| T-03-71 | Tampering | migration deploy step | mitigate | Documented as additive-only + reviewed before apply (03-01 gate); rollback = redeploy previous image |
| T-03-72 | Spoofing | env badge in production | accept | Build-time VITE_APP_ENV default production renders nothing; a misconfigured build only shows/mis-hides a badge |
| T-03-73 | Elevation | billing in production | mitigate | BILLING_PROVIDER=stripe documented as mandatory for production; mock webhook path is code-gated on the env value (03-02 T-03-15) |
| T-03-SC | Tampering | npm installs | accept | No installs in this plan |

</threat_model>
